# Private original-capture policy

Original game frames, recordings, dumps, disassemblies, and game data are not
source artifacts and must not be committed.  This directory may contain
text-only receipts that identify a privately held capture by state and
cryptographic hash.  Reproduce captures only from lawfully supplied media and
keep the resulting binary artifacts outside the repository.

Firestaff's test suite must use independently authored fixtures or read the
user-supplied game data at runtime; it must never require a checked-in original
capture.
