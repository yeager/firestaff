# DM1 DOS manual source notes

Source: `Dungeon-Master_Misc_DOS_EN_TXT-doc.zip` from the local Downloads
directory. The archive contains `Dungeon Master.txt` (27,254 bytes), a
gameplay manual rather than executable or graphics source.

The manual confirms these original DM1 interaction contracts:

- A Hall of Champions mirror is selected with the left mouse button.
- An object picked up with an empty hand changes the cursor to the picked
  object's image.
- A carried object can be moved to another location; compatible equipment is
  placed in the target slot and occupied slots swap as described by the game.
- A selected champion exposes the hand cursor in the dungeon view and object
  boxes; champion inventory is opened by right-clicking the champion name.
- Dungeon objects require the party to be close enough before pickup.
- The six movement controls are forward, backward, left/right strafe and
  left/right turn; wall controls must be directly in front of the party.

This document is behavioural evidence only. It is not used as a graphics or
runtime-data source, and it does not justify synthetic pixels or item names.
The authenticated PC 3.4 `GRAPHICS.DAT`, `DUNGEON.DAT`, `TITLE`, saves and
ReDMCSB source remain the implementation sources.
