# Firestaff 3.0.188

## Verified updates

- CSB V2.0, V2.1 and V2.2 verification coverage now passes against local
  PC3.4 data, including the title, Prison handoff, HUD, graphics settings,
  filters and admitted source-artpack routes.
- CSBWin standard `GRAPHICS.DAT` startup records are decoded from original
  data. The unproven modal C040 panel remains fail-closed rather than being
  presented as a runtime HUD surface.

## Packages

This release includes macOS, Windows, Linux, Steam Deck AppImage/package and
Artpack Studio artifacts produced by GitHub Actions.
