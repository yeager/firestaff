# CSB Atari Mania reference

Reviewed 2026-08-25. This is provenance and presentation reference material;
it does not replace hash verification or binary/source analysis.

## Local source

The supplied local PDF is:

```text
~/.firestaff/data/csb/Dungeon Master Expansion Set I - Chaos Strikes Back — PDF _ Atarimania.pdf
```

It is a 23-page print view of Atarimania's *Dungeon Master Expansion Set I -
Chaos Strikes Back* entry. The PDF's own print date is 2026-08-24; that is not
the game's publication date and must not be used as such.

## Retained facts

Atarimania identifies the Atari ST release as a 1989 commercial FTL/Software
Heaven title, in the low-resolution ST family, with mouse controls, one player,
English box/instructions, two single-sided disks, and a 0.5 MB ST/STE/Falcon
030 media note. Its page explicitly says that it needs the original *Dungeon
Master* to run.

These facts support Firestaff's existing product and platform documentation:

- CSB is an expansion, not a standalone PC/DOS title.
- Atari ST media and presentation must remain an independent native route.
- The supplied campaign disk is not interchangeable with a generic DM1 data
  directory or with CSBWin reference data.

The PDF also carries fifteen Atari ST screenshots, cover art and instruction
page scans. They are useful visual/provenance evidence for future source
capture comparison, but no screenshot pixels, UI coordinates or gameplay
semantics are admitted into production from them without a separate,
reproducible capture receipt.

## Relationship to executable evidence

Runtime behavior remains sourced from the selected, hash-verified original
Atari media (`.st`, `.stx`, `.msa` and/or their verified archive members),
ReDMCSB, and explicit regression evidence. In particular, the native
ANIMATE.SCR/ANIMATE.DAT 50 Hz title sequence and FTLCODE handoff are proven by
the original-media route, not inferred from the Atarimania scans.

The PDF is intentionally not copied into the repository and no original game
media or manual scan is distributed by Firestaff.
