# Game data

The maintained guide to required and optional original media is
[Game-data setup](../DATA_SETUP.md). It covers Dungeon Master, Chaos Strikes
Back, Dungeon Master II: Skullkeep, DM Nexus and Theron's Quest, including
disc and archive handling.

Use that guide when preparing a data folder. Firestaff verifies data by hash,
not by filename, and no original media is included with the engine.

The current runtime boundary for each game is documented separately in the
[project status](../PROJECT_STATUS.md).
