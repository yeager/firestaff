# Platform-card art

`platforms-source.png` is the high-resolution, source-owned six-cell product-art
atlas for the Firestaff launcher. `platforms.ppm` is its compact 384x256 runtime
derivative. It is deliberately P6 PPM so the native menu renderer needs no image
decoder or third-party runtime library.

The cells are ordered left-to-right, top-to-bottom:

1. FM Towns
2. PC / DOS
3. Atari ST
4. Amiga
5. Sega Saturn
6. PC Engine / TurboGrafx-16

These images decorate platform selection only. They do not contain, replace, or
derive from any game data.
